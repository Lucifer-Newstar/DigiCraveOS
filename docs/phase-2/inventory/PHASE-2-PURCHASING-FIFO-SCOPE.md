# Phase 2 — purchasing and FIFO inventory scope

This extends the existing inventory foundation and completes the purchasing/FIFO part of the Phase 2 roadmap.

## Included

- Suppliers
- Purchase receipt creation
- Purchase lines for ingredients, quantities, and unit costs
- Ingredient stock batches with received dates
- FIFO stock deduction from the oldest available batch
- Stock movement history through purchase receipts and order deductions
- Basic inventory valuation from remaining batch cost
- Admin-only API and inventory screen additions

## Not included

- Supplier marketplace
- Purchase order approval workflow
- Multi-outlet stock
- Expiry alerts
- Automatic procurement
- Accounting export

## Status

In progress — implementation started.
