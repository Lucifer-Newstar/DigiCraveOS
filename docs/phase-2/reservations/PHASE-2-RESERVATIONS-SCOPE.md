# Phase 2 — reservations and waitlist scope

This is the minimal reservations slice for DigiCraveOS Phase 2.

## Included

- Reservation creation with guest, date, time, party size, and optional table
- Reservation states: `Pending`, `Confirmed`, `Seated`, `Completed`, `Cancelled`, `No Show`
- Table assignment and basic availability checks
- Simple waitlist entries
- Staff/Admin management API and screen
- Validation for overlapping reservations
- Backend tests and implementation notes

## Not included

- Deposits or online reservation payments
- SMS/email notifications
- Recurring reservations
- Multi-outlet booking
- Advanced seating optimization
- External integrations

## Status

Implementation complete — runtime verification pending.
