# Phase 2 — shifts and payroll scope

This is the minimal workforce slice for the Phase 2 operations roadmap.

## Included

- Staff shift start and end records
- Attendance status: `Open`, `Closed`, `Absent`
- Break minutes and notes
- Staff shift history
- Admin summary of worked hours
- Basic payroll estimate using an hourly rate
- Admin-only workforce management screen and APIs
- Validation against duplicate open shifts

## Not included

- Payroll disbursement
- Tax deductions
- Leave management
- Rosters and overtime rules
- Biometric integrations
- Multi-outlet workforce

## Status

Implementation complete; runtime verification pending.
