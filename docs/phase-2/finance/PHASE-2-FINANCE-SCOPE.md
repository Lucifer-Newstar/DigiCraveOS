# Phase 2 — finance and GST reports scope

This is the minimal finance/reporting slice for the Phase 2 roadmap.

## Included

- Date-range revenue summary
- Order count and paid-order count
- CGST and SGST totals
- Payment-method breakdown
- Daily revenue rows
- Admin-only reports API and screen
- CSV-friendly tabular report data

## Not included

- Accounting-platform export
- Tax filing submission
- Reconciliation automation
- Multi-outlet consolidation
- Payroll disbursement

## Status

In progress — implementation started.
